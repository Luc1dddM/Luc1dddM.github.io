Thống kê và xác suất là trụ cột của khoa học dữ liệu và machine learning. Mọi ứng dụng trong Data Science, từ phân tích dữ liệu đơn giản đến các mô hình AI phức tạp, đều dựa trên những nguyên lý này.

💡 Tại sao quan trọng?

2. 📊 Thống Kê Mô Tả Cơ Bản

2.1. 🎯 Trung bình (Mean) - Điểm khởi đầu

Trung bình là thước đo trung tâm phổ biến nhất, nhưng có nhiều biến thể quan trọng cần hiểu rõ.

Các loại trung bình

Trung bình tổng thể (μ):

μ = (1/N) × ∑Xᵢ

Đây là giá trị trung bình của toàn bộ dữ liệu trong tổng thể.

Trung bình mẫu (x̄):

x̄ = (1/n) × ∑xᵢ

Là giá trị trung bình của một mẫu con được lấy từ tổng thể.

💻 Ví dụ thực tế

import numpy as np

# Dữ liệu mẫu
X = [2, 8, 5, 4, 1, 4]
sample_mean = sum(X) / len(X)
print(f"Trung bình mẫu: {sample_mean}")  # Kết quả: 4.0

# Sử dụng NumPy
mean_numpy = np.mean(X)
print(f"Trung bình (NumPy): {mean_numpy}")

🖼️ Ứng dụng trong xử lý ảnh

Trong xử lý ảnh, mean được sử dụng trong:

  • Kernel làm mờ (blurring) thông qua phép tích chập
  • Noise reduction bằng cách tính trung bình các pixel lân cận
  • Feature extraction để tính toán các đặc trưng cơ bản

2.2. 🛡️ Trung vị (Median) - Giá trị chống nhiễu

Trung vị là giá trị nằm chính giữa của tập dữ liệu sau khi sắp xếp, có khả năng chống lại nhiễu tốt hơn trung bình.

Công thức tính

  • Nếu N lẻ: Median = S₍ₙ₊₁₎/₂
  • Nếu N chẵn: Median = (Sₙ/₂ + S₍ₙ/₂₎₊₁)/2

🔧 Triển khai và so sánh

import numpy as np

# Dữ liệu có outlier
data_with_outlier = [2, 4, 5, 6, 8, 100]  # 100 là outlier

mean_val = np.mean(data_with_outlier)
median_val = np.median(data_with_outlier)

print(f"Trung bình: {mean_val:.2f}")    # 20.83 (bị ảnh hưởng bởi outlier)
print(f"Trung vị: {median_val}")        # 5.5 (không bị ảnh hưởng)

🖼️ Median Filter trong xử lý ảnh

Median filter rất hiệu quả trong khử nhiễu ảnh vì:

  • Loại bỏ salt-and-pepper noise
  • Bảo toàn cạnh của ảnh
  • Không làm mờ các chi tiết quan trọng
# Ví dụ median filter đơn giản
def median_filter_1d(data, window_size=3):
    result = []
    pad = window_size // 2
    padded_data = [data[0]] * pad + data + [data[-1]] * pad
    
    for i in range(len(data)):
        window = padded_data[i:i+window_size]
        result.append(np.median(window))
    
    return result

# Test
noisy_signal = [1, 2, 15, 4, 5, 6, 20, 8]  # 15, 20 là nhiễu
filtered = median_filter_1d(noisy_signal)
print(f"Tín hiệu gốc: {noisy_signal}")
print(f"Sau filter: {filtered}")

2.3. 📏 Phương sai và độ lệch chuẩn - Hiểu về sự phân tán

🤔 Tại sao phương sai mẫu dùng n-1?

Đây là một trong những câu hỏi quan trọng nhất! Việc sử dụng n-1 thay vì n được gọi là Hiệu chỉnh Bessel.

Phương sai tổng thể:

σ² = (1/N) × ∑(Xᵢ - μ)²

Phương sai mẫu:

s² = (1/(n-1)) × ∑(xᵢ - x̄)²

🧠 Giải thích lý do

Khía cạnh Giải thích
Vấn đề Trung bình mẫu (x̄) “gần gũi” với dữ liệu hơn trung bình tổng thể (μ)
Hệ quả Đánh giá thấp độ phân tán thực sự
Giải pháp Chia cho (n-1) để bù đắp sự thiên lệch
Khái niệm Bậc tự do: Khi biết x̄, chỉ còn (n-1) điểm “tự do”

💻 Minh họa bằng code

import numpy as np

# Tạo dữ liệu mẫu
np.random.seed(42)
population = np.random.normal(50, 15, 10000)  # μ=50, σ=15
true_var = np.var(population)  # Phương sai thực

# Lấy nhiều mẫu và so sánh
sample_size = 20
n_samples = 1000

biased_vars = []
unbiased_vars = []

for _ in range(n_samples):
    sample = np.random.choice(population, sample_size)
    
    # Phương sai thiên lệch (chia cho n)
    biased_var = np.sum((sample - np.mean(sample))**2) / sample_size
    biased_vars.append(biased_var)
    
    # Phương sai không thiên lệch (chia cho n-1)
    unbiased_var = np.sum((sample - np.mean(sample))**2) / (sample_size - 1)
    unbiased_vars.append(unbiased_var)

print(f"Phương sai thực của tổng thể: {true_var:.2f}")
print(f"Trung bình phương sai thiên lệch: {np.mean(biased_vars):.2f}")
print(f"Trung bình phương sai không thiên lệch: {np.mean(unbiased_vars):.2f}")

3. 🎲 Lý Thuyết Xác Suất

3.1. 🔢 Biến ngẫu nhiên (Random Variables)

Biến ngẫu nhiên là cầu nối giữa thế giới thực và toán học xác suất.

Phân loại và đặc điểm

Loại Đặc điểm Hàm đặc trưng Ví dụ
Rời rạc Giá trị đếm được PMF: P(X = x) Số lần tung xúc xắc
Liên tục Giá trị trong khoảng PDF: f(x) Chiều cao của người

📊 Hàm phân phối tích lũy (CDF)

Cho cả hai loại: F(x) = P(X ≤ x)

import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# Ví dụ với phân phối chuẩn
x = np.linspace(-4, 4, 1000)
pdf = stats.norm.pdf(x, 0, 1)  # PDF
cdf = stats.norm.cdf(x, 0, 1)  # CDF

# Quy tắc 68-95-99.7
print("Quy tắc 68-95-99.7 trong phân phối chuẩn:")
print(f"P(-1 ≤ X ≤ 1) = {stats.norm.cdf(1) - stats.norm.cdf(-1):.3f} ≈ 0.68")
print(f"P(-2 ≤ X ≤ 2) = {stats.norm.cdf(2) - stats.norm.cdf(-2):.3f} ≈ 0.95")
print(f"P(-3 ≤ X ≤ 3) = {stats.norm.cdf(3) - stats.norm.cdf(-3):.3f} ≈ 0.997")

3.2. 🎯 Giá trị kỳ vọng (Expected Value)

Định nghĩa toán học

Cho biến rời rạc:

E[X] = ∑ Xᵢ × P(Xᵢ)

Cho biến liên tục:

E[X] = ∫ x × f(x) dx

🔄 So sánh với Mean

Khía cạnh Mean Expected Value
Nguồn Dữ liệu đã thu thập Phân phối lý thuyết
Tính chất Giá trị quan sát được Giá trị dự kiến
Ứng dụng Mô tả dữ liệu hiện có Dự đoán và mô hình hóa

💡 Ví dụ thực tế - Game xúc xắc

# Tính expected value của game xúc xắc
outcomes = [1, 2, 3, 4, 5, 6]
probabilities = [1/6] * 6  # Xác suất đều nhau

expected_value = sum(x * p for x, p in zip(outcomes, probabilities))
print(f"Expected value của xúc xắc: {expected_value}")  # 3.5

# Mô phỏng để xác minh
n_simulations = 100000
simulated_rolls = np.random.choice(outcomes, n_simulations)
simulated_mean = np.mean(simulated_rolls)
print(f"Mean từ mô phỏng: {simulated_mean:.3f}")

4. 📈 Thống Kê Mô Tả Nâng Cao

4.1. 🤝 Hiệp phương sai (Covariance)

Hiệp phương sai đo lường mối quan hệ tuyến tính giữa hai biến.

Công thức và ý nghĩa

Công thức tổng quát:

Cov(X,Y) = E[(X - μₓ)(Y - μᵧ)]

Đối với mẫu:

Cov(X,Y) = (1/(n-1)) × ∑(xᵢ - x̄)(yᵢ - ȳ)

🎨 Giải thích trực quan

Giá trị Cov(X,Y) Ý nghĩa Diễn giải
> 0 Quan hệ thuận X tăng → Y có xu hướng tăng
< 0 Quan hệ nghịch X tăng → Y có xu hướng giảm
≈ 0 Không có quan hệ tuyến tính X và Y độc lập tuyến tính

💻 Triển khai và minh họa

import numpy as np
import matplotlib.pyplot as plt

# Tạo dữ liệu minh họa
np.random.seed(42)
n = 100

# Quan hệ thuận
x1 = np.random.randn(n)
y1 = 2 * x1 + np.random.randn(n) * 0.5
cov1 = np.cov(x1, y1)[0, 1]

# Quan hệ nghịch
x2 = np.random.randn(n)
y2 = -1.5 * x2 + np.random.randn(n) * 0.8
cov2 = np.cov(x2, y2)[0, 1]

# Không có quan hệ
x3 = np.random.randn(n)
y3 = np.random.randn(n)
cov3 = np.cov(x3, y3)[0, 1]

print(f"Covariance thuận: {cov1:.3f}")
print(f"Covariance nghịch: {cov2:.3f}")
print(f"Covariance gần 0: {cov3:.3f}")

⚠️ Hạn chế của Covariance

  • Phụ thuộc đơn vị đo: Khó so sánh giữa các bộ dữ liệu khác nhau
  • Khó diễn giải: Không có giới hạn rõ ràng
  • Chỉ đo quan hệ tuyến tính: Bỏ sót các mối quan hệ phi tuyến

4.2. ✨ Hệ số tương quan (Correlation Coefficient)

Hệ số tương quan khắc phục những hạn chế của covariance.

Công thức chuẩn hóa

Hệ số tương quan Pearson:

ρ(X,Y) = Cov(X,Y) / (σₓ × σᵧ)

🌟 Ưu điểm vượt trội

Ưu điểm Giải thích
Chuẩn hóa Luôn nằm trong [-1, 1]
Dễ diễn giải Giá trị càng gần ±1 càng mạnh
Không đơn vị Không bị ảnh hưởng bởi thay đổi tỷ lệ
So sánh được Có thể so sánh giữa các bộ dữ liệu khác nhau

📊 Thang đánh giá tương quan

Giá trị |r| Mức độ tương quan
0.00 - 0.19 Rất yếu
0.20 - 0.39 Yếu
0.40 - 0.59 Trung bình
0.60 - 0.79 Mạnh
0.80 - 1.00 Rất mạnh

💻 Code minh họa chi tiết

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import pearsonr

# Tạo dữ liệu với các mức độ tương quan khác nhau
def create_correlated_data(n, correlation):
    x = np.random.randn(n)
    y = correlation * x + np.sqrt(1 - correlation**2) * np.random.randn(n)
    return x, y

# Tạo các cặp dữ liệu
correlations = [0.9, 0.7, 0.3, 0.0, -0.7]
n_samples = 100

for i, target_corr in enumerate(correlations):
    x, y = create_correlated_data(n_samples, target_corr)
    actual_corr, p_value = pearsonr(x, y)
    
    print(f"Target correlation: {target_corr:4.1f}, "
          f"Actual: {actual_corr:5.3f}, "
          f"P-value: {p_value:.4f}")

5. ⚠️ Tương Quan vs Nhân Quả - Bẫy Lớn Nhất trong Phân Tích Dữ Liệu

🚨 Nguyên tắc vàng: “Correlation ≠ Causation”

Đây là một trong những nguyên tắc quan trọng nhất trong Data Science. Việc hiểu sai nguyên tắc này dẫn đến vô số kết luận sai lầm trong nghiên cứu và ứng dụng thực tế.

🕳️ Các bẫy phổ biến

1. 🎯 Biến thứ ba (Third Variable Problem)

Tình huống: Hai biến có tương quan cao nhưng không có mối quan hệ nhân quả trực tiếp.

Ví dụ kinh điển:

  • Quan sát: Doanh số kem và số ca đuối nước đều tăng
  • Kết luận sai: Kem gây đuối nước
  • Thực tế: Biến thứ ba là nhiệt độ cao (mùa hè)
# Mô phỏng ví dụ kem vs đuối nước
import numpy as np
import matplotlib.pyplot as plt

# Tạo dữ liệu giả lập
np.random.seed(42)
days = 365
temperature = 20 + 15 * np.sin(2 * np.pi * np.arange(days) / 365) + np.random.randn(days) * 2

# Cả hai đều phụ thuộc vào nhiệt độ
ice_cream_sales = np.maximum(0, (temperature - 15) * 10 + np.random.randn(days) * 20)
drowning_cases = np.maximum(0, (temperature - 20) * 0.1 + np.random.randn(days) * 0.5)

# Tính tương quan
correlation = np.corrcoef(ice_cream_sales, drowning_cases)[0, 1]
print(f"Tương quan kem vs đuối nước: {correlation:.3f}")
print("Nhưng không có mối quan hệ nhân quả trực tiếp!")

2. 🔄 Nhân quả ngược (Reverse Causality)

Vấn đề: Không rõ biến nào là nguyên nhân, biến nào là kết quả.

Ví dụ thực tế:

  • Quan sát: Thu nhập cao ↔ Sức khỏe tốt
  • Giả thuyết A: Thu nhập cao → Chăm sóc y tế tốt → Sức khỏe tốt
  • Giả thuyết B: Sức khỏe tốt → Làm việc hiệu quả → Thu nhập cao
  • Thực tế: Cả hai chiều đều có thể đúng!

3. 🎭 Tương quan giả mạo (Spurious Correlation)

Định nghĩa: Tương quan cao hoàn toàn ngẫu nhiên, không có ý nghĩa thực tế.

Ví dụ nổi tiếng:

  • Tỷ lệ ly hôn ở Maine vs Lượng tiêu thụ margarine: r = 0.99
  • Số PhD toán học vs Doanh thu rạp chiếu phim: r = 0.95

🔬 Cách thiết lập nhân quả đúng đắn

Phương pháp Mô tả Ưu điểm Hạn chế
Thí nghiệm có kiểm soát Thay đổi biến độc lập, đo biến phụ thuộc Mạnh nhất Tốn kém, đôi khi không khả thi
Nghiên cứu dọc Theo dõi cùng đối tượng qua thời gian Quan sát xu hướng Mất thời gian, attrition
Phân tích đa biến Kiểm soát nhiều biến cùng lúc Loại bỏ confounding Phức tạp, cần dữ liệu lớn
Instrumental Variables Sử dụng biến công cụ Xử lý endogeneity Khó tìm IV phù hợp

💡 Framework đánh giá nhân quả

Tiêu chí Bradford Hill (dành cho dịch tệ học)

  1. Strength: Mối quan hệ càng mạnh càng có khả năng nhân quả
  2. Consistency: Kết quả nhất quán qua nhiều nghiên cứu
  3. Temporality: Nguyên nhân phải xảy ra trước kết quả
  4. Dose-response: Tăng nguyên nhân → tăng kết quả
  5. Plausibility: Có cơ chế giải thích hợp lý
# Tool đánh giá nhanh tương quan vs nhân quả
def evaluate_causation(correlation_strength, temporal_order, confounding_controlled, mechanism_explained):
    """
    Đánh giá khả năng mối quan hệ nhân quả
    
    Parameters:
    - correlation_strength: float (0-1) - độ mạnh tương quan
    - temporal_order: bool - nguyên nhân có xảy ra trước kết quả không
    - confounding_controlled: bool - đã kiểm soát biến thứ ba chưa
    - mechanism_explained: bool - có giải thích được cơ chế không
    """
    
    score = 0
    factors = []
    
    if correlation_strength > 0.7:
        score += 2
        factors.append("Tương quan mạnh ✓")
    elif correlation_strength > 0.3:
        score += 1
        factors.append("Tương quan trung bình ~")
    else:
        factors.append("Tương quan yếu ✗")
    
    if temporal_order:
        score += 2
        factors.append("Thứ tự thời gian đúng ✓")
    else:
        factors.append("Thứ tự thời gian không rõ ✗")
    
    if confounding_controlled:
        score += 2
        factors.append("Đã kiểm soát confounding ✓")
    else:
        factors.append("Chưa kiểm soát confounding ✗")
    
    if mechanism_explained:
        score += 1
        factors.append("Có cơ chế giải thích ✓")
    else:
        factors.append("Không có cơ chế rõ ràng ✗")
    
    # Đánh giá tổng thể
    if score >= 6:
        conclusion = "🎯 Có khả năng cao là nhân quả"
    elif score >= 4:
        conclusion = "⚠️ Cần nghiên cứu thêm"
    else:
        conclusion = "❌ Khả năng thấp là nhân quả"
    
    return {
        'score': score,
        'max_score': 7,
        'factors': factors,
        'conclusion': conclusion
    }

# Ví dụ sử dụng
result = evaluate_causation(
    correlation_strength=0.85,
    temporal_order=True,
    confounding_controlled=True,
    mechanism_explained=False
)

print(f"Điểm: {result['score']}/{result['max_score']}")
print("Các yếu tố:")
for factor in result['factors']:
    print(f"  - {factor}")
print(f"\nKết luận: {result['conclusion']}")

6. 🖼️ Ứng Dụng trong Xử Lý Ảnh

6.1. 📊 Histogram và ứng dụng

Histogram là công cụ cơ bản nhưng mạnh mẽ trong xử lý ảnh, cung cấp thông tin về phân bố cường độ sáng.

Các loại Histogram quan trọng

Các loại Histogram quan trọng

1. Density Histogram (Histogram mật độ):

h[b] = n_b / N
  • n_b: số pixel ở bin b
  • N: tổng số pixel
  • Tổng các bin = 1 (xác suất)

2. Cumulative Histogram (Histogram tích lũy):

H[b] = ∑(k=0 to b) h[k]
  • Cho biết tỷ lệ pixel có cường độ ≤ b
  • Giá trị cuối cùng luôn = 1

💻 Triển khai Histogram

import numpy as np
import matplotlib.pyplot as plt

def compute_histogram(image, bins=256):
    """Tính toán các loại histogram cho ảnh grayscale"""
    
    # Flatten image to 1D array
    pixels = image.flatten()
    
    # Frequency histogram
    freq_hist, bin_edges = np.histogram(pixels, bins=bins, range=(0, 255))
    
    # Density histogram (PMF)
    density_hist = freq_hist / len(pixels)
    
    # Cumulative histogram (CDF)
    cumulative_hist = np.cumsum(density_hist)
    
    return {
        'frequency': freq_hist,
        'density': density_hist,
        'cumulative': cumulative_hist,
        'bin_centers': (bin_edges[:-1] + bin_edges[1:]) / 2
    }

6.2. ⚖️ Cân bằng Histogram (Histogram Equalization)

Histogram Equalization là kỹ thuật tăng độ tương phản bằng cách phân bố lại các mức xám.

🎯 Mục đích và Nguyên lý

Mục tiêu: Biến đổi ảnh để histogram trở nên phân bố đều hơn Nguyên lý: Sử dụng CDF như hàm biến đổi

📐 Công thức toán học

Công thức chính:

b_new = (L-1) × H[b] + 0.5

Trong đó:

  • L: số mức xám (thường là 256)
  • H[b]: giá trị CDF tại mức xám b
  • +0.5: làm tròn

🔧 Quy trình thực hiện

  1. Tính frequency histogram từ ảnh gốc
  2. Chuyển đổi thành PMF (chia cho tổng số pixel)
  3. Tính CDF (tích lũy PMF)
  4. Áp dụng công thức biến đổi
  5. Tạo ảnh mới với các giá trị đã biến đổi

💻 Triển khai chi tiết

def histogram_equalization(image):
    """
    Thực hiện histogram equalization cho ảnh grayscale
    """
    # Bước 1: Tính histogram
    hist, bins = np.histogram(image.flatten(), 256, [0, 256])
    
    # Bước 2: Tính CDF
    cdf = hist.cumsum()
    
    # Bước 3: Chuẩn hóa CDF
    cdf_normalized = cdf * 255 / cdf[-1]
    
    # Bước 4: Áp dụng biến đổi
    equalized = np.interp(image.flatten(), bins[:-1], cdf_normalized)
    
    # Reshape về kích thước gốc
    equalized = equalized.reshape(image.shape).astype(np.uint8)
    
    return equalized, cdf_normalized

⚡ Adaptive Histogram Equalization (AHE)

Để khắc phục hạn chế của HE truyền thống (có thể làm mất chi tiết cục bộ):

def adaptive_histogram_equalization(image, window_size=50):
    """
    Thực hiện Adaptive Histogram Equalization
    """
    rows, cols = image.shape
    result = np.zeros_like(image)
    
    # Tạo padding
    pad = window_size // 2
    padded = np.pad(image, pad, mode='reflect')
    
    for i in range(rows):
        for j in range(cols):
            # Lấy window xung quanh pixel hiện tại
            window = padded[i:i+window_size, j:j+window_size]
            
            # Thực hiện HE trên window này
            equalized_window, _ = histogram_equalization(window)
            
            # Lấy giá trị pixel trung tâm
            center = window_size // 2
            result[i, j] = equalized_window[center, center]
    
    return result

def template_matching_ncc(image, template):
    """
    Template matching sử dụng Normalized Cross-Correlation
    """
    from scipy.signal import correlate2d
    
    # Chuẩn hóa template và image
    template_norm = (template - np.mean(template)) / np.std(template)
    
    result = []
    h, w = template.shape
    
    for i in range(image.shape[0] - h + 1):
        row_result = []
        for j in range(image.shape[1] - w + 1):
            # Lấy patch từ image
            patch = image[i:i+h, j:j+w]
            patch_norm = (patch - np.mean(patch)) / np.std(patch)
            
            # Tính correlation
            correlation = np.sum(template_norm * patch_norm) / (h * w)
            row_result.append(correlation)
        result.append(row_result)
    
    return np.array(result)

def customer_analysis_pipeline(sales_data):
    """
    Pipeline phân tích khách hàng sử dụng thống kê
    """
    results = {}
    
    # 1. Descriptive Statistics
    results['mean_purchase'] = np.mean(sales_data['amount'])
    results['median_purchase'] = np.median(sales_data['amount'])
    results['std_purchase'] = np.std(sales_data['amount'], ddof=1)
    
    # 2. Customer Value Distribution
    q1 = np.percentile(sales_data['amount'], 25)
    q3 = np.percentile(sales_data['amount'], 75)
    iqr = q3 - q1
    
    # Phát hiện outliers
    lower_bound = q1 - 1.5 * iqr
    upper_bound = q3 + 1.5 * iqr
    outliers = sales_data[(sales_data['amount'] < lower_bound) | 
                         (sales_data['amount'] > upper_bound)]
    
    results['outliers_count'] = len(outliers)
    results['outlier_ratio'] = len(outliers) / len(sales_data)
    
    # 3. Correlation Analysis
    if 'frequency' in sales_data.columns:
        correlation = np.corrcoef(sales_data['amount'], sales_data['frequency'])[0,1]
        results['amount_frequency_correlation'] = correlation
    
    # 4. Customer Segments
    segments = {
        'high_value': sales_data[sales_data['amount'] > results['mean_purchase'] + results['std_purchase']],
        'medium_value': sales_data[
            (sales_data['amount'] >= results['mean_purchase'] - results['std_purchase']) &
            (sales_data['amount'] <= results['mean_purchase'] + results['std_purchase'])
        ],
        'low_value': sales_data[sales_data['amount'] < results['mean_purchase'] - results['std_purchase']]
    }
    
    results['segments'] = {k: len(v) for k, v in segments.items()}
    
    return results, segments

A/B Testing Framework

def ab_test_analysis(control_group, treatment_group, alpha=0.05):
    """
    Phân tích A/B test sử dụng statistical inference
    """
    from scipy.stats import ttest_ind, chi2_contingency
    
    results = {}
    
    # Descriptive Statistics
    results['control'] = {
        'mean': np.mean(control_group),
        'std': np.std(control_group, ddof=1),
        'n': len(control_group)
    }
    
    results['treatment'] = {
        'mean': np.mean(treatment_group),
        'std': np.std(treatment_group, ddof=1),
        'n': len(treatment_group)
    }
    
    # Effect Size (Cohen's d)
    pooled_std = np.sqrt(((results['control']['n']-1)*results['control']['std']**2 + 
                         (results['treatment']['n']-1)*results['treatment']['std']**2) / 
                        (results['control']['n'] + results['treatment']['n'] - 2))
    
    cohens_d = (results['treatment']['mean'] - results['control']['mean']) / pooled_std
    results['effect_size'] = cohens_d
    
    # Statistical Test
    t_stat, p_value = ttest_ind(control_group, treatment_group)
    results['t_statistic'] = t_stat
    results['p_value'] = p_value
    results['significant'] = p_value < alpha
    
    # Confidence Interval for difference
    diff = results['treatment']['mean'] - results['control']['mean']
    se_diff = np.sqrt(results['control']['std']**2/results['control']['n'] + 
                     results['treatment']['std']**2/results['treatment']['n'])
    
    from scipy.stats import t
    t_critical = t.ppf(1 - alpha/2, results['control']['n'] + results['treatment']['n'] - 2)
    ci_lower = diff - t_critical * se_diff
    ci_upper = diff + t_critical * se_diff
    
    results['confidence_interval'] = (ci_lower, ci_upper)
    
    # Interpretation
    if abs(cohens_d) < 0.2:
        effect_interpretation = "Small effect"
    elif abs(cohens_d) < 0.5:
        effect_interpretation = "Medium effect"
    else:
        effect_interpretation = "Large effect"
    
    results['interpretation'] = effect_interpretation
    
    return results

# Mô phỏng A/B test
np.random.seed(42)
control = np.random.normal(100, 15, 500)    # Conversion rate 100
treatment = np.random.normal(108, 15, 480)  # Improved by 8%

print(f"Significant: {test_results['significant']}")
print(f"95% CI: ({test_results['confidence_interval'][0]:.2f}, {test_results['confidence_interval'][1]:.2f})")
print(f"Interpretation: {test_results['interpretation']}")

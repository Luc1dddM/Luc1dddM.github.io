1. Nền Tảng Xác Suất Cơ Bản

1.1. 📊 Biến cố và Không gian mẫu

Xác suất là nền tảng toán học cho việc xử lý tính bất định trong AI. Hiểu rõ các khái niệm cơ bản là bước đầu quan trọng.

Các khái niệm cốt lõi

  • Thí nghiệm ngẫu nhiên: Hoạt động có kết quả không thể dự đoán chắc chắn
  • Không gian mẫu (Ω): Tập hợp mọi kết quả có thể xảy ra
  • Biến cố (Event): Tập con của không gian mẫu
# Ví dụ minh họa
import numpy as np

# Thí nghiệm: Tung xúc xắc
omega = [1, 2, 3, 4, 5, 6]  # Không gian mẫu
event_even = [2, 4, 6]      # Biến cố "ra số chẵn"
event_odd = [1, 3, 5]       # Biến cố "ra số lẻ"
event_greater_3 = [4, 5, 6] # Biến cố "ra số > 3"

print(f"Không gian mẫu: {omega}")
print(f"Biến cố số chẵn: {event_even}")
print(f"Xác suất ra số chẵn: {len(event_even)/len(omega)}")

🔄 Các phép toán trên biến cố

Phép toán Ký hiệu Ý nghĩa Ví dụ
Giao A ∩ B Xảy ra cả A và B {số chẵn} ∩ {số > 3} = {4, 6}
Hợp A ∪ B Xảy ra A hoặc B {số chẵn} ∪ {số > 4} = {2, 4, 5, 6}
Phủ định A’ Không xảy ra A {số lẻ}’ = {2, 4, 6}
Loại trừ A ∩ B = ∅ A và B không thể cùng xảy ra {chẵn} ∩ {lẻ} = ∅

📈 Định nghĩa và tính chất xác suất

Xác suất cổ điển: P(A) = Số trường hợp thuận lợi / Tổng số trường hợp có thể

Tính chất cơ bản:

  • 0 ≤ P(A) ≤ 1: Xác suất luôn trong khoảng [0, 1]
  • P(Ω) = 1: Xác suất của không gian mẫu bằng 1
  • P(∅) = 0: Xác suất của biến cố rỗng bằng 0
  • P(A’) = 1 - P(A): Xác suất biến cố phủ định

🎲 Xác suất có điều kiện và Luật nhân

Xác suất có điều kiện P(A|B) là xác suất A xảy ra khi biết B đã xảy ra:

P(A|B) = P(A ∩ B) / P(B)

Luật nhân xác suất:

P(A ∩ B) = P(A) × P(B|A) = P(B) × P(A|B)

1.2. 🌟 Định lý Bayes - Trụ cột của AI

Định lý Bayes là một trong những công cụ mạnh mẽ nhất trong AI, cho phép cập nhật niềm tin dựa trên bằng chứng mới.

Công thức tổng quát

P(A|B) = [P(B|A) × P(A)] / P(B)

Trong ngữ cảnh AI

P(Giả thuyết|Bằng chứng) = [P(Bằng chứng|Giả thuyết) × P(Giả thuyết)] / P(Bằng chứng)

🔬 Phân tích từng thành phần

Thành phần Tên gọi Ý nghĩa Vai trò
P(A|B) Xác suất hậu nghiệm Xác suất A khi biết B Kết quả cần tìm
P(B|A) Likelihood (Khả năng) Xác suất B khi A đúng Độ ủng hộ của bằng chứng
P(A) Xác suất tiên nghiệm Xác suất A ban đầu Kiến thức có sẵn
P(B) Bằng chứng biên Tổng xác suất B Hằng số chuẩn hóa

💡 Ý nghĩa và tầm quan trọng

Định lý Bayes cho phép:

  • Đảo ngược xác suất: Từ “Xác suất bằng chứng khi có giả thuyết” → “Xác suất giả thuyết khi có bằng chứng”
  • Cập nhật động: Liên tục cập nhật niềm tin khi có thông tin mới
  • Xử lý bất định: Đưa ra quyết định trong điều kiện thiếu thông tin

1.3. 🧠 Naive Bayes Classifier - Ứng dụng kinh điển

Naive Bayes Classifier áp dụng định lý Bayes để phân loại dữ liệu, đặc biệt hiệu quả với văn bản.

Nguyên lý hoạt động

Công thức cho phân loại:

P(Class|Features) = [P(Features|Class) × P(Class)] / P(Features)

🤔 Giả định “ngây thơ”

Giả định độc lập có điều kiện: Các đặc trưng (từ) độc lập với nhau khi đã biết lớp.

Tại sao “ngây thơ” nhưng hiệu quả?

  • Giả định hiếm khi đúng trong thực tế
  • Nhưng không ảnh hưởng nghiêm trọng đến thứ tự xếp hạng các xác suất
  • Đơn giản, nhanh, ít yêu cầu dữ liệu

💻 Triển khai thực tế với Python

import numpy as np
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# Tập dữ liệu mẫu
emails = [
    ("Free money now! Click here!", "spam"),
    ("Hey, meeting at 3 PM tomorrow.", "ham"),
    ("Urgent: Claim your prize!", "spam"),
    ("Project update for next week.", "ham")
]

# Tách dữ liệu và vector hóa
texts = [email[0] for email in emails]
labels = [email[1] for email in emails]
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(texts)

# Huấn luyện mô hình
classifier = MultinomialNB()
classifier.fit(X, labels)

# Dự đoán email mới
def predict_email(text, classifier, vectorizer):
    text_vec = vectorizer.transform([text])
    prediction = classifier.predict(text_vec)[0]
    probabilities = classifier.predict_proba(text_vec)[0]
    return prediction, max(probabilities)

# Test với email mới
new_email = "Claim your free lottery prize now!"
result, confidence = predict_email(new_email, classifier, vectorizer)
print(f"Dự đoán: {result} (độ tin cậy: {confidence:.3f})")

1.4. 🚀 Ứng dụng nâng cao trong AI

🕸️ Mạng Bayes (Bayesian Networks)

Mạng Bayes là đồ thị có hướng không chu trình biểu diễn mối quan hệ xác suất giữa các biến.

Ứng dụng thực tế:

  • Chẩn đoán y tế: Suy luận bệnh từ triệu chứng
  • Chẩn đoán lỗi: Tìm nguyên nhân sự cố hệ thống
  • Ra quyết định: Tối ưu hóa trong bất định

🎯 Tối ưu hóa Bayes

Tối ưu hóa hàm mục tiêu đắt đỏ (ví dụ: điều chỉnh siêu tham số) bằng cách xây dựng mô hình thay thế.

🧬 Mạng Nơ-ron Bayes

Đặc điểm:

  • Trọng số là phân phối: Thay vì số cố định
  • Định lượng bất định: Đo độ tin cậy dự đoán
  • Robust: Tránh overfitting

1.5. 🎯 Tổng kết và triển vọng

Kiến thức đã học

  • Nền tảng xác suất: Biến cố, không gian mẫu, xác suất có điều kiện
  • Định lý Bayes: Công cụ cập nhật niềm tin từ bằng chứng
  • Naive Bayes: Phân loại hiệu quả với giả định đơn giản
  • Ứng dụng nâng cao: Mạng Bayes, tối ưu hóa, Neural Networks

🚀 Tầm quan trọng trong AI

Lĩnh vực Ứng dụng Bayes Lợi ích
NLP Phân loại văn bản, dịch máy Xử lý ngôn ngữ tự nhiên

2. Kiến Thức Mở Rộng

2.1. ⚡ Aggregation Framework

MongoDB Aggregation Framework là “dàn nhạc giao hưởng” của xử lý dữ liệu MongoDB, hoạt động theo mô hình pipeline mạnh mẽ.

Cấu trúc Pipeline

db.collection_name.aggregate([
  {$match: {criteria}},        // Lọc dữ liệu
  {$project: {fields}},        // Chọn và tạo trường
  {$group: {_id, operations}}, // Gom nhóm và tổng hợp
  {$sort: {field: 1}},         // Sắp xếp
  {$limit: N}                  // Giới hạn kết quả
]);

🔍 Các Stage Quan Trọng

  • $match: Bộ lọc mạnh mẽ như WHERE trong SQL
  • $project: Tùy biến tầm nhìn dữ liệu, tương tự SELECT
  • $group: Gom nhóm và áp dụng phép tổng hợp ($sum, $avg, $max)
  • $facet: Chạy nhiều pipeline song song trên cùng dữ liệu
  • $bucket: Phân loại dữ liệu vào các nhóm
  • $lookup: Thực hiện join với collection khác
  • $unwind: Tách mảng thành các document riêng biệt

Ví dụ thực tế - Phân tích doanh thu

// Tính doanh thu theo tháng và danh mục sản phẩm
db.orders.aggregate([
  {
    $match: {
      orderDate: {
        $gte: ISODate("2024-01-01"),
        $lt: ISODate("2025-01-01")
      }
    }
  },
  {
    $group: {
      _id: {
        month: {$month: "$orderDate"},
        category: "$product.category"
      },
      totalRevenue: {$sum: "$amount"},
      orderCount: {$sum: 1},
      avgOrderValue: {$avg: "$amount"}
    }
  },
  {
    $sort: {"_id.month": 1, totalRevenue: -1}
  }
]);

2.2. 📈 Indexes

Indexes là “bí mật của tốc độ” trong MongoDB, giúp tăng hiệu suất truy vấn lên hàng trăm lần.

Các loại Index quan trọng

// 1. Single Field Index
db.collection.createIndex({field: 1})  // Tăng dần
db.collection.createIndex({field: -1}) // Giảm dần

// 2. Compound Index
db.collection.createIndex({field1: 1, field2: -1})

// 3. Multikey Index (cho arrays)
db.collection.createIndex({tags: 1})

// 4. Text Index (full-text search)
db.collection.createIndex({title: "text", content: "text"})

// 5. Partial Index (chỉ index một phần)
db.collection.createIndex(
  {email: 1}, 
  {partialFilterExpression: {status: "active"}}
)

// 6. TTL Index (tự động xóa)
db.collection.createIndex(
  {createdAt: 1}, 
  {expireAfterSeconds: 3600}
)

🔧 Tối ưu hóa và Monitoring

// Phân tích hiệu suất query
db.collection.find({field: "value"}).explain("executionStats")

// Xem các index hiện có
db.collection.getIndexes()

// Theo dõi usage của index
db.collection.aggregate([{$indexStats: {}}])

// Tìm các query chậm
db.setProfilingLevel(2, {slowms: 100})
db.system.profile.find().sort({ts: -1}).limit(5)

⚠️ Best Practices cho Indexes

  • ESR Rule: Equality, Sort, Range - thứ tự tối ưu cho compound index
  • Selectivity: Đặt trường có selectivity cao lên đầu
  • Index Intersection: MongoDB có thể kết hợp nhiều index
  • Monitor regularly: Theo dõi index usage và hiệu suất

2.3. 🐍 MongoDB Drivers (Python)

PyMongo là driver chính thức của MongoDB cho Python, cung cấp API đầy đủ và hiệu suất cao.

Kết nối và cấu hình cơ bản

from pymongo import MongoClient
from pymongo.errors import ConnectionFailure
import pymongo

# Kết nối với các tùy chọn
client = MongoClient(
    'mongodb://localhost:27017/',
    maxPoolSize=50,
    wtimeout=2500,
    serverSelectionTimeoutMS=5000
)

# Kiểm tra kết nối
try:
    client.admin.command('ping')
    print("MongoDB connection successful!")
except ConnectionFailure:
    print("Failed to connect to MongoDB")

# Chọn database và collection
db = client['ecommerce']
products = db['products']
orders = db['orders']

CRUD Operations nâng cao

# Create - Bulk operations
bulk_ops = []
for i in range(1000):
    bulk_ops.append(
        pymongo.InsertOne({
            "name": f"Product {i}",
            "price": i * 10.5,
            "category": "electronics" if i % 2 else "books"
        })
    )

result = products.bulk_write(bulk_ops)
print(f"Inserted {result.inserted_count} documents")

# Read - Advanced queries with projections
pipeline = [
    {"$match": {"price": {"$gte": 100, "$lte": 500}}},
    {"$project": {"name": 1, "price": 1, "discounted_price": {"$multiply": ["$price", 0.9]}}},
    {"$sort": {"price": -1}},
    {"$limit": 10}
]

expensive_products = list(products.aggregate(pipeline))

# Update - Advanced operations
update_result = products.update_many(
    {"category": "electronics"},
    {
        "$mul": {"price": 1.1},  # Tăng giá 10%
        "$set": {"updated_at": datetime.utcnow()},
        "$inc": {"view_count": 1}
    }
)

print(f"Updated {update_result.modified_count} documents")

# Delete - Conditional deletion
delete_result = products.delete_many({
    "price": {"$lt": 10},
    "view_count": {"$lt": 5}
})

Aggregation với Python

# Complex aggregation pipeline
def get_sales_report(start_date, end_date):
    pipeline = [
        {
            "$match": {
                "order_date": {
                    "$gte": start_date,
                    "$lte": end_date
                }
            }
        },
        {
            "$lookup": {
                "from": "products",
                "localField": "product_id",
                "foreignField": "_id",
                "as": "product_info"
            }
        },
        {
            "$unwind": "$product_info"
        },
        {
            "$group": {
                "_id": {
                    "category": "$product_info.category",
                    "month": {"$month": "$order_date"}
                },
                "total_revenue": {"$sum": "$amount"},
                "order_count": {"$sum": 1},
                "avg_order_value": {"$avg": "$amount"},
                "top_products": {
                    "$push": {
                        "name": "$product_info.name",
                        "revenue": "$amount"
                    }
                }
            }
        },
        {
            "$sort": {"total_revenue": -1}
        }
    ]
    
    return list(orders.aggregate(pipeline))

# Sử dụng
from datetime import datetime, timedelta
start = datetime(2024, 1, 1)
end = datetime(2024, 12, 31)
report = get_sales_report(start, end)

for item in report:
    print(f"Category: {item['_id']['category']}")
    print(f"Month: {item['_id']['month']}")
    print(f"Revenue: ${item['total_revenue']:,.2f}")
    print("-" * 40)

Error Handling và Best Practices

from pymongo.errors import (
    BulkWriteError,
    DuplicateKeyError,
    WriteError
)

def safe_insert_product(product_data):
    try:
        result = products.insert_one(product_data)
        return {"success": True, "id": result.inserted_id}
    except DuplicateKeyError:
        return {"success": False, "error": "Product already exists"}
    except WriteError as e:
        return {"success": False, "error": str(e)}

# Connection pooling và timeout
def create_optimized_client():
    return MongoClient(
        'mongodb://localhost:27017/',
        maxPoolSize=100,           # Tối đa 100 connections
        minPoolSize=10,            # Tối thiểu 10 connections
        maxIdleTimeMS=45000,       # Timeout cho idle connections
        waitQueueTimeoutMS=5000,   # Timeout chờ connection
        serverSelectionTimeoutMS=5000,
        socketTimeoutMS=20000,
        connectTimeoutMS=20000,
        retryWrites=True
    )
